# Olympics_Data_Analysis

Olympic Games Data Analysis
About the project

This project was created as a comprehensive Power BI showcase, combining different techniques and features I learned while working with data.

The report explores Olympic Games data from multiple perspectives, including sports, countries, medals and athletes. My goal was not only to analyze the dataset, but also to build an interactive report that demonstrates different ways of exploring and presenting information in Power BI.

The dashboard includes multiple report pages, interactive filters, drill-through pages, custom tooltips, DAX measures and dynamic visual elements. Some visuals also change depending on the selected sport, making the report more interactive and easier to explore.
